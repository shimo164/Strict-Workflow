# Modifications Made After Forking
This is a fork of the Strict Workflow Chrome extension. The following changes have been made:

- Timer Stop: Added the ability to stop the timer with a confirmation dialog.
- Settings in Block Mode: Settings can now be modified even while the extension is in block mode.
- CSS for Options Page: Added styles/options.css to improve the styling of the options page.
- Version Update: Updated the extension to Manifest V3 and refactored the code accordingly.
